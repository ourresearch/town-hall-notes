# OpenAlex Town Hall Notes

Update notes for [OpenAlex](https://openalex.org) community meetings: the quarterly community town hall, the Community Advisory Board (CAB), and the Members Meeting (a smaller roundtable with paying Member-tier institutions, in between the public town halls).

Each meeting has a directory with up to four files:

- **retro** — what we shipped
- **roadmap** — what's next
- **transcript** — recording link + full transcript of the session
- **followups** — questions Jason said he'd check on, plus small fixes / feature requests promised on the call

The retros are generated with the help of an AI agent (Claude Code) using our open-source repos, blog, and commit history as sources. The exact prompt is included at the top of each retro — so anyone can reproduce or adapt the process.
